# Real-Time Systems Assignments 

In this git repo, you will receive all the template code and submit the solutions for the two assignments you have to complete as part of the RTS course.

For each assignment, there will be a seperate folder. E.g. Assignment A is in the folder `assignment-a`. The report for each assignment should go inside the corresponding assignment folder. For instance, the report for Assignment A should be placed in `assignment-a/assignment_a_report_group_X.pdf`.

The assignments and lab-setup have been published on the [course website](https://cese.ewi.tudelft.nl/real-time-systems/).
